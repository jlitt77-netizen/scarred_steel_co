# Brand assets

Official Scarred Steel Co. logo files live here. Supplied by the owner — do not
regenerate or recreate the mark.

Drop the logo here (any of these; PNG is fine):
- logo-full.png   — primary lockup (used in headers, login, portal)
- logo-compact.png (optional) — square/icon version for tight spaces
- logo-mono.png    (optional) — single-color version

Once a file is present, src/components/ui/Logo.tsx is switched on to use it.
